개인정보처리방침

최종 업데이트: 2026년 5월 27일

락인포커스는 광고 없음 · 구독 없음 · 추적 없음 앱입니다.
수집한 데이터를 외부에 판매하거나 공유하지 않습니다.

1. 수집하는 정보

앱 사용에 필요한 최소한의 정보만 기기에 저장합니다.

  • 닉네임 — 사용자가 직접 입력. 랭킹 기능 사용 시 iCloud에 저장.
  • 집중 점수 — 기기 내부 및 iCloud에 저장. 랭킹 기능 사용 시 CloudKit에 업로드.
  • 앱 선택 정보 — iOS Screen Time API가 관리하는 불투명 토큰으로 저장. 어떤 앱인지 개발자는 알 수 없습니다.
  • 스케줄 설정 — 시작/종료 시각, 요일. 기기 내부에만 저장.
  • 앱 비밀번호 — SHA-256 해시 형태로 Keychain에 저장. 평문 저장 없음.

2. 수집하지 않는 정보

  • 광고 식별자 (IDFA)
  • 위치 정보
  • 연락처, 카메라, 마이크
  • 실제 사용 앱 목록 (Screen Time API 정책상 개발자에게 노출 안 됨)
  • 기기 분석 데이터 또는 충돌 로그

3. 데이터 저장 위치

  • 기기 내부 — 스케줄, 집중 점수, 설정값 (UserDefaults / Keychain)
  • iCloud — 닉네임, 집중 점수 (Apple이 관리하는 NSUbiquitousKeyValueStore)
  • CloudKit Public DB — 랭킹 기능 사용 시 닉네임 + 점수만 저장 (Apple 서버)

별도의 개발자 운영 서버는 없습니다.

4. 제3자 공유

수집한 데이터를 제3자에게 판매, 공유, 임대하지 않습니다. 광고 네트워크, 분석 SDK를 사용하지 않습니다.

5. 아동 개인정보 보호

락인포커스는 만 13세 미만 아동으로부터 의도적으로 개인정보를 수집하지 않습니다.

Privacy Policy

Last updated: May 27, 2026

Lockin Focus is a no-ads · no-subscription · no-tracking app.
We do not sell or share your data with third parties.

1. Information We Collect

We store only the minimum information necessary to provide the app's features, on your device.

  • Nickname — Entered by the user. Stored in iCloud when using the leaderboard.
  • Focus scores — Stored on device and iCloud. Uploaded to CloudKit when using the leaderboard.
  • App selection — Stored as opaque tokens managed by iOS Screen Time API. We cannot see which apps you select.
  • Schedule settings — Start/end times and weekdays. Stored on device only.
  • App passcode — Stored as a SHA-256 hash in the iOS Keychain. Never stored in plain text.

2. Information We Do Not Collect

  • Advertising identifiers (IDFA)
  • Location data
  • Contacts, camera, or microphone
  • Actual app usage history (not exposed to developers by Screen Time API)
  • Analytics or crash reporting data

3. Data Storage

  • On device — Schedule, focus scores, settings (UserDefaults / Keychain)
  • iCloud — Nickname, focus scores (Apple-managed NSUbiquitousKeyValueStore)
  • CloudKit Public DB — Nickname and scores only, when using leaderboard (Apple servers)

There are no developer-operated servers.

4. Third-Party Sharing

We do not sell, share, or rent your data to any third party. No ad networks or analytics SDKs are used.

5. Children's Privacy

Lockin Focus does not knowingly collect personal information from children under the age of 13.
